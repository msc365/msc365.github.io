# msc365.github.io

Personal website of Martin Swinkels, built with [Astro](https://astro.build) and hosted on GitHub Pages at <https://www.msc365.eu>.

## Develop

```bash
npm install
npm run dev
npm run build
```

Posts are Markdown files in `src/content/posts/`. The site deploys from `main` through `.github/workflows/deploy.yml`.
